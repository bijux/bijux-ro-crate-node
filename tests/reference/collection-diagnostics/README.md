# Collection diagnostics

Diagnostic labels inspect the report graph. They render a partial collection's
available prefix; OWL inference separately requires a complete LIST antecedent.
`ordinary-inputs.json` and `ordinary-reference.json` retain twelve exact Python
controls for partial/complete lists, literal members and insertion order.

Three cyclic lists expose a Python renderer failure: `Graph.items` raises,
pySHACL loses the required inverse-path finding, and Python approves the crate.
The corrected counterpart preserves the prefix and appends the existing
`<http://recursion.too.deep>` marker. All three crates must be rejected with the
complete finding; the original approval remains recorded separately.

`capture.py` accepts only these three registered inputs and pins the formatter,
report clone and graph iterator hashes. It corrects only the two recursive-rest
diagnostic failures in memory. Valid neighboring crates remain valid. Installed
Python, OWL traversal and ordinary comparison stay unchanged.
`checks.mjs` permits exactly one specified finding and its exception copy to be
added per case, with every other input/result field preserved.
