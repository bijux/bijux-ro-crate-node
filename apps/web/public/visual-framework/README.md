# Visual Framework assets

This directory contains the Visual Framework v2.5.12 CSS rollup and its
referenced local fonts and SVG assets. The stylesheet is sourced from
`https://assets.emblstatic.net/vf/v2.5.12/css/styles.css`; the corresponding
[release](https://github.com/visual-framework/vf-core/releases/tag/v2.5.12)
is distributed under the Apache License 2.0 in [LICENSE](LICENSE).

The original stylesheet has SHA-256
`fb486ba796c4018d70279b67e7688bac182a6b830db8b1175c352669f82c7a0f`.
The local copy differs only by replacing two references to an unrelated remote
roundel background image with `none`. Its SHA-256 is
`2ef4cc3aca1e0a761875cb17acabe34c5c266bddbfa7e37fa6e21ce6f08ee0c2`.
All remaining relative assets are copied from the same v2.5.12 distribution.

IBM Plex fonts are distributed under the SIL Open Font License 1.1; see
[IBM-Plex-LICENSE.txt](IBM-Plex-LICENSE.txt).
